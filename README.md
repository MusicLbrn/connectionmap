This project is an outgrowth of working with a performing arts professor to illustrate their “creative scholarship” in a way that was more tangible than a spreadsheet or list of places and performances.
The impact map was generated using base code provided by the R Graph Gallery and the background is a NASA night lights image.  Locations of interest were scraped from the professor’s CV and coded for time period: pre-current university, pre-previous promotion, previous promotion to present. These places were then used as points of connection on the map, with each connecting back to the point of origin, the current university.
